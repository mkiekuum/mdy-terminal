MDY Terminal v5.3.0
1. 解压 chrome.zip 到固定文件夹，里面应直接有 manifest.json。
2. Chrome 打开 chrome://extensions，开启开发者模式，加载已解压的扩展程序。
3. 登录MDY 计划站；独立建图点「MCP新建计划」，无需选旧计划。核对新图预览后确认一次，保存不会自动送审。
4. 删除/恢复先核对差异；结果未知点“检查原请求”，不要重复写入。
5. 原目录覆盖更新后，在扩展管理页重新加载；没有自动安装保证。
可选本机 MCP 见源码包 mcp/README.md，无需公网。无旧业务 CLI、Native Messaging、本地问卷或 AI API 设置。最近十批历史仅在原浏览器保存。
使用同版便携服务；已有配对会重连。首次或恢复连接：扩展「MCP修改计划」，本人允许浏览器访问本机，再把复制的一次性编号交给可信本机 Agent。无需打开、导入或发送连接文件。
正式安装说明：https://github.com/mkiekuum/mdy-terminal/releases/latest

外部图纸：请向 AI 明确允许修改的范围。原分类节点与辅助点不同；不要为适配网站擅自改依赖。仅预览的 JSON 不会保存；图形一致不代表计算准确。
