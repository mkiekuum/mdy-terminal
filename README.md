# 序图终端 v4.0.0

打开序图计划，输入需求，复制给 AI，再粘贴返回的 JSON 并执行。终端会自动识别当前序图页。有多个候选时，切到要处理的计划即可。

在设置中可保存序图账号并启用自动登录。首页适配窄窗口与深色模式，按需展开历史记录、页面复制及设置。

可选本机 MCP 让 AI 检查连接、登录、读取当前计划、预览变更、执行已确认的操作并查询结果。扩展与服务端应使用同一版本。首次配对从“复制给 MCP AI”开始。
