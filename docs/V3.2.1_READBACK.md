# 3.2.1 服务器回读修复

实际序图 MCP 创建草稿时，保存成功后网站会在箭头补齐 `visualIgnore:false`，而原提交没有提供此字段。旧版会因此把已经保存的草稿误报成无法回读确认。修复只接受「提交时未设置、读取时明确为 false」这一已核实的默认值。真实的显示设置、工期、负责人、编号和箭头变化仍不能被忽略。

验收包括一项模拟真实保存响应的 API 回归，以及能拒绝真实显示或工期变化的负向测试。真站的新建回读验收需在重新加载 3.2.1 后单独验证。

更新工具也核实了 macOS 临时路径带符号链接时的命令入口：预览不会替换，实际执行后必须读回安装目录中的新版清单。
