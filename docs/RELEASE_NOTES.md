# 序图终端 v4.1.0

首页默认复制给 MCP AI。需求可留空，由 AI 询问目标。修改已有计划时核对计划、版本和字段，再预览影响。需要选择时可用数字回复本次列出的选项。

展开「JSON 指令」可复制普通 AI 提示词或手动执行。点击「复制全部历史记录」可交给 AI 核对本机当前账号保留的最近十批，预览并恢复到指定批次之前或之后。

页面导出提供复制 DOM 和下载离线 HTML。检测到新的正式版本时，终端顶部会显示更新建议。

计划编辑支持网站授予编辑权的助理与协作者。新建或复制时核对负责人权限。需求框可描述跨计划、跨任务操作。

安装方法见 docs/WINDOWS_INSTALL.md，本机 MCP 配置见 mcp/README.md。
