# 序图终端 v4.4.0

- 新增计划图、项目、任务、申请审批工作范围，支持刷新、搜索、选择具体记录以及复制对应上下文。
- MCP 新增 records.meta、records.projects、records.tasks、records.requests，以及 records.submit、records.review、records.link。
- 新建项目和任务统一提交审核，普通成员修改提交申请，审核员可显式选择直接修改。待审核申请显示“等待审核”。
- 修改、审核、关联使用最新完整 before 核对目标，执行后回读。记录接口没有原子版本条件，并发限制会显示在预览中。
- 任务名称由类型和工程名生成，负责人、类型及状态从服务端元数据核对。
- 保留已有计划图与进度操作、历史记录和设置存储。

验证使用隔离模拟服务端及无头 Chrome。真实网站公开前端已核对，登录浏览器会话检查超时，新增记录的真实服务端写入尚未验收。旧 project.create 仍为项目组接口，新流程请使用 records.submit。
