# MDY Terminal v4.6.0

- 产品与 GitHub 仓库更名为 MDY Terminal / mdy-terminal，更新入口同步迁移。
- 侧栏只保留“隐藏旧计划栏”开关，移除旧点击展开与浮动恢复控件，不干预 MDY 网站导航。
- 删除工作范围选择器、配色与密度设置，以及底部版本和复制更新指令；更新建议只在顶部出现。
- 保留统一卡片，单按钮满宽、双按钮等分，JSON 默认折叠，空需求仍可复制提示词。
- 既有 MCP 指令、历史记录、账号、配对密钥和存储键保持兼容；已存的旧外观偏好不清空，新界面跟随系统。

更名升级必须覆盖原扩展目录，不卸载后重装，不清空浏览器存储。文件替换后在扩展管理页重新加载。

验证：202 项测试通过，Windows 跳过 1 项 macOS 路径测试；隔离 Chrome 验证 280/400/880px、深浅模式、复制、执行、历史恢复与设置保留。Codex 浏览器读取已登录的实际 MDY 页面，并对本版源码的本地 UI 预览逐项操作及截图验收。UI 预览使用模拟扩展接口，不代表已将新版加载进用户 Chrome；本次没有生产业务写入。v4.4.0 新记录接口的生产写入验收与并发限制继续适用。
