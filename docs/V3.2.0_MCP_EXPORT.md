# 3.2.0 MCP 扩展验收

2026-11-15，候选版。更新范围：新增 MCP 文件导出、限定 DOM/HTML 读取、跨计划整图／区域复制和设置中的自动登录，以及 AI 核实原位置后更新文件、由用户重新加载的流程。原有首页、侧栏、页面复制、历史、执行按钮保留；权限清单未扩大。

| 功能 | 验收 | 边界 |
| --- | --- | --- |
| MCP 文件存档 | 真正的 HTTP MCP 调用经过浏览器桥契约、落盘两个 CSV、返回路径和 SHA-256。实际 Chromium 输出中文 PDF、PNG、SVG 与测试 HTML。 | PDF 使用网站图和原生计算重排，不是自动操作原网页打印窗口；未在正式计划上跑新版导出。 |
| DOM | 测试限定 DOM 读取、实时输入值、遮掉密码/脚本/外链及身份变化保护。Codex 内置浏览器以已有授权凭据登录真实序图，读取到 41 个图中序号。 | 内置浏览器只读核对不等于扩展已经安装或桥接。 |
| 跨计划复制与新建删除 | 合成网站覆盖预览不写入、源与目标版本冲突、权限阻拦、合成计划新建及垃圾桶读回；正式记录保持。 | 从未向正式网站提交；借用同事计划仍需要网站赋权及本次提交确认。 |
| 设置 | 已测试保存状态不回显、命中序图登录表单、不会对外站发送、存在验证码时不尝试、有限重试、清除后停用。 | 密码保存在扩展本地 IndexedDB，由用户开启；未在已部署浏览器中验重启后的自动登录。 |
| 网站功能范围 | 站点已确认的读和写沿用正式契约；新增复制、导出和限制范围的 DOM。 | 未声称任意网站按钮、权限管理、硬删除、全量历史或任意脚本已经支持；查 `system.capabilities` 和实际网站权限。 |

单元及接口测试 188 项通过。新增端到端回归覆盖实际 HTTP、浏览器桥、扩展后台与文件导出；确认站点版本变化时不生成新文件。原目录替换、保留用户文件、备份、权限扩大与本地改动时拒绝覆盖，都通过了隔离目录测试。隔离 Chrome 用合成网页验证既有插件页面与离线输出；未接触真实计划。Codex 内置浏览器打开真实计划成功，但扩展管理页被浏览器策略拦截，本轮未替换运行中的插件、未校验真实 MCP 连通或做真实写入。

安装及输出目录见[本机 MCP 说明](../mcp/README.md)。真实验收时先读 `system.version` 和 `site.context`，确认 3.2.0 能读取指定标签；再导出一份其版本对得上的文件。若需试写，展示独立测试计划的创建和回收范围，按提交前确认执行，再读回垃圾桶。
